# 🐍 Snake Game

A simple and fun Snake Game built with Python and Pygame.

## 🎮 Features

- 📱 Mobile touch controls
- 🏆 High score system
- ⭐ Score tracking
- 📈 Multiple levels
- ⚡ Increasing game speed
- 🔄 Restart button
- 💀 Game Over system
- 🎯 Random food generation

## 🛠️ Technologies Used

- Python
- Pygame
